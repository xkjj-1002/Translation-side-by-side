# 隐私说明

扩展没有自建翻译服务器或统计埋点。所选翻译引擎决定正文是否发送到外部服务。

- 浏览器内置 AI：由浏览器下载语言包，模型就绪后在本地翻译。
- 有道或大模型接口：用户触发翻译时，正文发送到所配置的服务商或接口；动态增量开启后，新增待翻译内容也可能发送给该服务。
- 备用引擎：启用在线备用引擎时，后续翻译也可能通过该服务处理。
- 本地演示：仅生成模拟译文。

密钥与配置保存在浏览器本地扩展存储中；翻译缓存也在本地保存。在线翻译服务如何处理数据，取决于其自身隐私政策与用户配置。发送反馈前请移除密钥、私人页面正文和个人信息。

本说明描述当前产品的数据路径。未来如有变化，将随对应版本更新。仓库私有期间，此文档不能充当面向公众的商店隐私政策网址。
