# 商店上架文案（可直接复制粘贴）

> 用于 Chrome Web Store 开发者控制台 与 Microsoft Edge Partner Center。
> 两个商店的字段名略有不同，下面按字段逐项给出。

---

## 1. 扩展名称 / Extension name

```
即时翻译 · 双语对照
```

来源：`manifest.json` 的 `name` 字段。两个商店都会自动读取，改这里没用，要改得改 manifest。

## 2. 简短说明 / Short description

```
按一下快捷键，当前网页的外语正文在每段下方直接出现中文译文，原文保留，可随时切回。
```

来源：`manifest.json` 的 `description` 字段，共 41 字符（Chrome 上限 132）。Edge 也读这个字段作为短描述。

## 3. 详细说明 / Description

> Edge 要求 **250 ~ 10000 字符**；Chrome 没有硬性下限但审核偏好详尽。下面这版 **1394 字符**，两边都能用。

```
即时翻译 · 双语对照 —— 按一下快捷键，外语网页在每一段下方直接出现中文译文，原文一字不动。

■ 为什么是「双语对照」，而不是整页替换

机器翻译一定会有出错的时候。整页替换式的翻译把译文盖在原文上，一旦译错，你连「它到底翻错了什么」都看不出来。
这个扩展反过来：原文完整保留，译文只追加在每一段下方。看不懂就往下看译文，信不过就抬头看原文，随时按一次快捷键把译文全部隐藏，页面回到干净的原样。

■ 怎么用

按 Alt+T（macOS 为 ⌥ Option+T）翻译当前页，再按一次隐藏译文，第三次恢复显示。
译文的显示与隐藏不产生任何网络请求，隐藏后立刻再显示是瞬时的。也可以只用 Alt+Shift+T 单独切换译文显隐。

■ 主要能力

• 段落级对照 —— 正文段落、列表、表格单元、标题都能识别；译文插在原文下方，不改动原文一个字
• 批量合并请求 —— 同一页的正文按字符预算和段数上限分桶，一次请求翻一批，整页通常十秒内完成
• 回拆严格校验 —— 批量翻译最怕「3 段回成 2 段」导致译文串行。本扩展严格校验返回编号的集合、顺序与段数，任何一条不满足就退回逐段翻译。宁可慢，不可错位
• 动态内容自动增量 —— 无限滚动、SPA 切页新增的正文会被自动接住并补翻，不用反复按快捷键（有每分钟段数上限，避免刷爆额度）
• 翻译缓存 —— 内存加持久化两层 LRU，同一段文字翻过就不再请求
• 主动限速与自动恢复 —— 被接口限流时进入全局冷却并逐步恢复，而不是继续撞墙；页面上会如实显示「访问过于频繁，已自动降速，约 N 秒后继续」
• 站点规则 —— 自动识别有误差时，选中要处理的区域，用工具栏面板一键「排除选中区域」或「只翻译指定区域」，规则按域名保存
• 跟随宿主页面明暗主题，译文样式与页面协调

■ 四种翻译引擎，自己选

1. 浏览器内置 AI（默认）—— 用 Chrome / Edge 自带的翻译模型，免费、完全本地、文本不上传。需要 Chrome 138+ / Edge 148+ 且设备达标，首次使用要下载语言包。
2. 有道智云 —— 便宜、稳定、快，适合日常大量阅读。
3. 大模型 API —— 一个 OpenAI 兼容实现覆盖 DeepSeek / OpenAI / Anthropic Claude，也能填任何兼容接口（本地 Ollama、vLLM 都行）。译文质量最好，按 token 计费。
4. 本地演示 —— 不需要任何密钥，用于先看排版效果（译文带【模拟译文】前缀，不是真实翻译）。

切换引擎后，已翻译的页面会提示你重译，一键换成新引擎的版本。

■ 密钥与隐私

• 密钥只保存在浏览器本地存储中，只有扩展后台能读
• 注入网页的脚本拿到的永远是脱敏副本（所有密钥字段被剔除），网页本身完全接触不到
• 大模型接口地址通过运行时权限申请，只申请你填的那一个域名，而不是安装时就要「访问所有网站」
• 没有统计、没有埋点、没有账号、没有自建服务器。你的按键、浏览记录都不经过我们

■ 关于网络

译文由你选择的服务商生成，需要能访问到该服务商。扩展对「连不上」的处理是快速、如实地告诉你并给出出路，而不是一直转圈或悄悄用假译文充数。

■ 适合谁

经常读外语资料、论文、新闻、文档，希望看懂而不是替换原文的人。
```

## 7. 权限说明 / Permission justification

逐条复制到商店后台对应权限的输入框：

| 权限 | 填写内容 |
|---|---|
| `storage` | 保存用户自己填写的翻译引擎配置与密钥、站点规则、翻译缓存和限流状态。这些数据全部只存在浏览器本地，不会上传到任何我们控制的服务器。 |
| `activeTab` | 用户通过快捷键或工具栏图标**主动触发**翻译时，对当前标签页生效。扩展不会在后台自动操作任何标签页。 |
| `https://openapi.youdao.com/*` | 调用有道智云文本翻译接口。这是该翻译服务唯一需要的域名。仅当用户主动选择「有道智云」并填入自己的密钥、并按下翻译快捷键时才会请求。 |
| `https://*/*`（可选权限） | 仅当用户主动选择「大模型 API」并填写了自定义接口地址时，才在运行时按需申请**该一个域名**，用于把待翻译文本发到用户自己的接口。用户不填写则不申请，扩展也不会请求任何其他域名。 |
| 内容脚本 `http://*/*`、`https://*/*` | 用户可能在任何网站上阅读外语内容，扩展需要能在任意页面注入译文层。扩展**不读取页面内容**，除非用户主动按下翻译快捷键；此时只读取当前页待翻译的正文文本。 |

## 8. 数据使用披露 / Data usage

⚠️ **这一项必须如实勾选，是本扩展审核最容易出问题的地方。**

**要勾选「网站内容（Website content）」**：

```
仅在用户主动按下翻译快捷键时，读取当前页面的正文文本，并发送给「用户自己所配置的」翻译服务
（有道智云，或用户自行填写的大模型接口地址）以生成译文。
若用户选择「浏览器内置 AI」，则文本在本机处理，不离开设备。
我们自身不接收、不存储、不记录这些文本。
```

**不要勾选**：个人身份信息、健康信息、金融与支付信息、身份验证信息、个人通讯、位置、浏览历史、用户活动。

**要勾选/确认的声明**：

- ✅ 不向第三方出售或转让用户数据
- ✅ 不将数据用于与扩展核心功能无关的用途
- ✅ 不将数据用于判定信用度或用于放贷
- ✅ 数据的使用限于提供扩展所声明的单一用途（翻译）

> 权限审计依据（可用来回答审核问询）：扩展源码中只有两处网络请求 ——
> `src/shared/providers/youdao.js`（有道接口）和 `src/shared/providers/llm.js`（用户自填接口），
> 全仓库不存在任何统计、埋点或遥测代码。

## 9. 隐私政策 / Privacy policy

商店要求提供一个**可公开访问的 URL**。把下面这段放到 GitHub Pages、Gist 或任意静态托管上，再把链接填进去。

```
即时翻译 · 双语对照 —— 隐私政策

最后更新：2026 年 9 月 30 日

一、我们不收集什么

本扩展没有账号系统，没有统计分析，没有埋点，没有广告，也没有由我们运营的服务器。
我们不会收集、存储或传输你的按键记录、浏览历史、身份信息或使用行为。

二、数据会去哪里

1. 你的翻译引擎配置与密钥
   仅保存在你浏览器本地的扩展存储（chrome.storage.local）中。
   只有扩展的后台脚本能读取；注入到网页的脚本只能拿到剔除密钥后的脱敏副本，
   被翻译的网页本身无法接触这些信息。

2. 待翻译的文本
   只有在你主动按下翻译快捷键（或点击翻译按钮）时，扩展才会读取当前页面的正文文本，
   并把它发送给你所选择的翻译服务以生成译文：
   - 选择「浏览器内置 AI」：文本由浏览器内置模型在本机处理，不离开你的设备。
   - 选择「有道智云」：文本发送至有道智云的文本翻译接口（openapi.youdao.com）。
   - 选择「大模型 API」：文本发送至你自己填写的接口地址。
   扩展不会把文本发送给上述之外的任何一方，我们自身也接收不到这些文本。
   第三方服务对其收到的数据的处理，适用该服务自己的隐私政策。

3. 翻译缓存
   已翻译的文本与其译文会缓存在浏览器本地，用于避免重复请求。可在设置页清除。

三、我们不做什么

我们不出售、不转让用户数据；不将数据用于广告、画像或信用评估；
不将数据用于与「翻译网页正文」这一核心功能无关的任何目的。

四、权限用途

- storage：在本地保存你的配置、密钥与缓存。
- activeTab：在你主动触发时对当前标签页生效。
- 访问 openapi.youdao.com：调用有道翻译接口。
- 可选的主机权限：仅在你填写了自定义大模型接口地址时，按需申请那一个域名。
- 在所有网站上注入内容脚本：为了能在你打开的任何网页上显示译文。
  扩展不会读取页面内容，除非你主动按下翻译快捷键。

五、你的控制权

你可以在设置页随时清除缓存、删除已保存的密钥，或直接卸载扩展。
卸载后本地保存的全部数据一并删除。

六、联系方式

（请在此填写你的联系邮箱或问题反馈地址）
```

## 10. 审核备注 / Notes for certification

提交时填这一段，能显著减少审核来回：

```
本扩展没有任何默认可用的翻译服务，因此审核时请按下面步骤验证：

1. 安装后会自动打开设置页。
2. 在「服务商」下拉中选择「本地演示（无需密钥）」——这是专为审核准备的离线演示引擎，
```
