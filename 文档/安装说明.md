这个文件夹是**可直接发布的成品**，不包含源码、`node_modules`、测试和开发脚本。

| 路径 | 用途 |
|---|---|
| `instant-translate-v0.2.1.zip` | **提交商店用**。`manifest.json` 已在压缩包根目录，可直接上传 Chrome Web Store / Edge Add-ons |

| `发布清单.md` | 上架步骤与逐项检查表 |
| `SHA256SUMS.txt` | 校验和，用于确认分发包没有被改动 |

## 一、本地安装（不用等审核，马上能用）

### Chrome

1. 地址栏打开 `chrome://extensions`
2. 打开右上角**开发者模式**
3. 点**加载已解压的扩展程序**
4. 选择本文件夹里的 **`instant-translate-v0.2.1/`** 目录
   （不是 `发布版/` 根目录，那里没有 `manifest.json`）

### Edge

把第 1 步换成 `edge://extensions`，其余完全一样。Edge 是 Chromium 内核，本扩展行为一致。

首次安装会自动打开设置页。

## 二、从商店安装

等 `instant-translate-v0.2.1.zip` 通过审核上架后，用户直接在商店点「添加至 Chrome / 获取」即可。
上架流程见 `发布清单.md`。

## 三、安装之后要做的第一件事：配一个翻译引擎

扩展装好但**还没法翻译**，因为默认引擎「浏览器内置 AI」在中国大陆经常连不上模型服务器。
打开设置页（工具栏图标 → 设置），按下面选一家：

| 引擎 | 适合谁 | 说明 |
|---|---|---|
| **有道智云** | 想便宜稳定、不想折腾 | 新账号送 50 元体验金，最省事。到 [有道智云](https://ai.youdao.com/appmgr.s) 建应用，**服务平台必须选「文本翻译」**，把应用 ID 和密钥填进设置页 |
| **大模型 API** | 要最好的译文质量 | 设置页有 DeepSeek / OpenAI / Claude 快速填充预设，按 token 计费 |
| **浏览器内置 AI** | 免费且完全本地 | 需 Chrome 138+ / Edge 148+ 且设备达标，首次要下语言包。**在大陆通常下不动** |

填完点**「测试连接」**确认能用。

## 四、怎么用

| 操作 | Windows / Linux | macOS |
|---|---|---|
| 翻译 / 隐藏 / 恢复译文 | `Alt` + `T` | `⌥ Option` + `T` |
| 显示 / 隐藏译文 | `Alt` + `Shift` + `T` | `⌥ Option` + `Shift` + `T` |
| 翻译中停止并隐藏 | 再按一次翻译键 | 再按一次翻译键 |

> **Mac 键盘上没有印着「Alt」的键**，对应的是 `Option`（⌥），在最下面一排 Command 的右侧。

**按键没反应**：点工具栏图标，popup 里会显示**当前真正生效的键位**。
若显示「未绑定」，点里面的「打开快捷键设置」手动指定一个组合键
（Mac 上 Option 组合键较常见地被系统占用）。

## 五、验证这版是可用的

发布前已在源码仓库跑过：

- `npm test` —— **208 项全部通过**（单元 / 契约 / 架构验收 / jsdom 集成 / 产物冒烟）
- `npm run verify:browser` —— 真实 Chrome 加载本包产物、用真实按键跑完整链路：
  内置 AI 语言包下载 → **22 段真实译文注入** → 语言包卡死时给出可见结论与补救入口
  → 连按三次的「翻译 / 隐藏 / 显示」循环（22 段全程不变，不重复请求）
- `npm run build` —— 产物与 `instant-translate-v0.2.1/` 内容一致

> 真机脚本依赖浏览器的内置 Translator 服务，在本机上偶发 `NotSupportedError`
> 或浏览器自身崩溃（CDP socket closed），属环境波动，不是扩展缺陷 ——
> 扩展遇到这种情况会**如实提示并尝试回落**，不会假装翻译成功。

想自己确认这一包没问题，装好后打开 `test-page.html` 那张验收页
（源码仓库根目录，或用 `python3 -m http.server 8199` 起个本地服务）逐条过一遍。

## 六、这版的已知限制

发布时不隐藏问题，商店文案里也如实写了：

- **子框架（iframe）内的正文暂不翻译** —— 为避免同一段文字被翻多次
- **正文主体识别还没做** —— 复杂页面上可能翻到侧栏噪声，用 popup 里的「站点规则」手工排除
- **单段超过 5000 字符会失败**（有道接口上限）
- **大模型译文可能出现增删或意译**，重要内容请对照原文
- 内置 AI 的设备门槛不低（Chrome 138+ / Edge 148+、16GB 内存、22GB 可用磁盘）

完整设计与说明见源码仓库的 `README.md`。
