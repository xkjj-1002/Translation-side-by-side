# 即时翻译 · 双语对照

按一下快捷键（`Alt/⌥ + T`），当前网页的外语正文就在**每段下方直接出现中文译文**，原文保留，再按一次随时切回。

Chrome / Edge 的 Manifest V3 扩展。**本仓库只提供发布版成品，不含源码。**

- 版本：**0.2.1**
- 支持：Chrome 114+ / Edge 114+（浏览器内置 AI 引擎需要 Chrome 138+ / Edge 148+，且设备达标）
- 许可：见下方「许可与反馈」

---

## 一、安装（不用等审核，马上能用）

### Chrome

1. 把本仓库下载到本地（`Code → Download ZIP`，或 `git clone`）
2. 地址栏打开 `chrome://extensions`
3. 打开右上角**开发者模式**
4. 点**加载已解压的扩展程序**，选择**本仓库根目录**（就是能看到 `manifest.json` 的那一层）

### Edge

把第 2 步换成 `edge://extensions`，其余完全一样。Edge 是 Chromium 内核，行为一致。

首次安装会自动打开设置页。

## 二、装完先配一个翻译引擎

扩展装好但**还不能翻译**——默认引擎「浏览器内置 AI」在中国大陆经常连不上模型服务器。
在设置页四选一：

| 引擎 | 费用 | 需要联网 | 说明 |
|---|---|---|---|
| 浏览器内置 AI | 免费 | 仅首次下载语言包 | 完全本地推理，隐私最好；有设备门槛 |
| 有道智云 | 按量计费，有免费额度 | 是 | 需要 appKey / appSecret |
| 大模型 API | 按 token 计费 | 是 | 任意 OpenAI 兼容接口：DeepSeek / OpenAI / Claude / 本地 Ollama 都行 |
| 本地演示 | 免费 | 否 | 离线可用的模拟译文，用来先看效果 |

## 三、目录里有什么

| 路径 | 用途 |
|---|---|
| `manifest.json`、`content.js`、`bg/`、`options/`、`popup/`、`icons/` | **扩展本体**。加载已解压扩展时选仓库根目录 |
| `商店素材/` | 商店图标与宣传图，尺寸已按商店要求生成 |
| `文档/安装说明.md` | 更细的安装与排查步骤 |
| `文档/发布清单.md` | 上架步骤、逐项检查表、版本记录 |
| `文档/商店文案.md` | 商店列表文案、权限说明、隐私声明 |
| `文档/SHA256SUMS.txt` | 校验和，用于确认文件没有被改动 |

## 四、隐私

- 扩展**不收集、不上传**任何数据，没有统计埋点，没有远程代码。
- 只有两处网络请求，且都由你的操作触发：
  1. 你按下翻译快捷键时，把**当前页的正文文本**发给你自己选定的翻译服务（有道 / 你自填的大模型接口）；
  2. 内置 AI 引擎首次使用时，由**浏览器**自行下载语言包（不经过本扩展的服务器）。
- 兜底引擎一旦启用，就是**每次**按下快捷键都会把正文发给它，而不是偶然一次。
- 详细的权限理由与数据处理说明见 `文档/商店文案.md`。

## 五、许可与反馈

本仓库仅分发构建产物。**源码未公开**，因此这里不提供开源许可；你可以自由安装、使用与卸载本扩展。

问题反馈请在**本仓库的 Issues** 里提出，附上：浏览器与版本、页面地址、以及 `<html>` 上的 `data-itx-state` / `data-itx-engine` 两个属性值。
